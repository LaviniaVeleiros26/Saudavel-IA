# Apresentação — Saudável IA

Apresentação de Larissa, Lavínia e Raissa, com oito slides, nas cores do site.

## Baixar os arquivos

- [Baixar tudo em ZIP](https://github.com/LaviniaVeleiros26/Saudavel-IA/raw/refs/heads/apresentacao-saudavel-ia/apresentacao/Saudavel-IA-completa.zip)
- [Baixar PowerPoint editável](https://github.com/LaviniaVeleiros26/Saudavel-IA/raw/refs/heads/apresentacao-saudavel-ia/apresentacao/Saudavel-IA.pptx)
- [Baixar apresentação em PDF](https://github.com/LaviniaVeleiros26/Saudavel-IA/raw/refs/heads/apresentacao-saudavel-ia/apresentacao/Saudavel-IA.pdf)
- [Ler o roteiro de fala](Roteiro-de-apresentacao.md)

Se abrir um arquivo individual no GitHub, use o botão **Download raw file**, com ícone de seta para baixo. O PowerPoint pode ser aberto no computador ou importado para o Google Apresentações. O PDF mantém o visual para leitura.

A apresentação segue os cinco tópicos pedidos: o problema, por que escolhemos o tema, demonstração ao vivo, o que deu errado e o que aprendemos. A resposta exibida como exemplo é ilustrativa; durante a demonstração, mostrem o resultado real do site. As frases das integrantes são sugestões para adaptação.

Esta branch adiciona somente os materiais de apresentação. Não altera o código do site.
